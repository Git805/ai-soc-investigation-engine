# Requirements

## Functional
- FR-001 Accept security alerts through an API.
- FR-002 Normalize heterogeneous telemetry into a common schema.
- FR-003 Correlate events by host, user, process, file, hash, domain, IP and time.
- FR-004 Store investigation evidence.
- FR-005 Enrich IOCs with attributable intelligence.
- FR-006 Map evidence to MITRE ATT&CK techniques.
- FR-007 Build an investigation storyline/graph.
- FR-008 Generate structured AI investigation hypotheses.
- FR-009 Validate AI outputs against a strict schema.
- FR-010 Capture analyst feedback.
- FR-011 Generate investigation reports.
- FR-012 Maintain an auditable investigation history.

## Non-functional
- NFR-001 Reproducible local deployment.
- NFR-002 Secure secret handling.
- NFR-003 API authentication and authorization.
- NFR-004 Explainable AI outputs with supporting evidence.
- NFR-005 Prompt-injection resistance.
- NFR-006 Model-output validation.
- NFR-007 Observable services.
- NFR-008 Portable containerized deployment.
